# Minimum Add to Make Parentheses Valid

**LeetCode:** [921 - Minimum Add to Make Parentheses Valid](https://leetcode.com/problems/minimum-add-to-make-parentheses-valid/)

**Difficulty:** Medium

**Topic:** Stack, Parentheses

**Language:** C++

## Problem

A parentheses string is valid if and only if it is empty, can be written as `AB` where both `A` and `B` are valid strings, or can be written as `(A)` where `A` is valid.

Given a parentheses string `s`, in one move you can insert a parenthesis at any position.

Return the minimum number of moves required to make `s` valid.
